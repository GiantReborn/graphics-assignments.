Computer Graphics Assignments

Three 2D animation projects

Name: Otun Gideon Oreoluwa

Matric Number: CPE/2022/1084

This showcase presents three computer graphics assignments demonstrating object movement, continuous animation, and screen-boundary behaviour.

1. Bouncing Ball

Project description

A ball moves continuously inside a bounded screen area. When it reaches an edge, its direction changes so it remains visible within the display.

Concepts demonstrated

  • 2D object positioning and translation
  • Continuous animation
  • Boundary detection and direction reversal

Expected result

The ball repeatedly bounces around the display without leaving the screen.

2. Moving Car

Project description

A car travels horizontally across the screen. When it moves beyond one edge, it re-enters from the opposite side to create continuous movement.

Concepts demonstrated

  • 2D object translation
  • Horizontal movement
  • Screen-edge detection and position reset

Expected result

The car continuously crosses the display and reappears from the other side.

3. Moving Moon

Project description

A full moon moves across a night sky. Stars decorate the background to create a simple night-time scene while the moon travels across the display.

Concepts demonstrated

  • 2D object translation
  • Scene composition and background elements
  • Continuous animation

Expected result

The moon travels across the starry sky and repeats its movement.

Project Overview

Course area: Computer Graphics

Project type: 2D animation demonstrations

Tools used in the original assignments: Godot Engine 4 and GDScript.

Browser demonstration: HTML and CSS animations presented in a lightweight webpage.

Purpose: To demonstrate basic computer graphics principles through object movement, animation, and screen-boundary behaviour.
